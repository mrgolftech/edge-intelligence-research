# 国产可信计算与商用密码标准证据索引（2026-09）

- 日期：2026-09-30
- 用途：支撑最终报告 Trust Plane、国产可信计算、TCM/安全芯片、商用密码算法和密码应用实施/测评等章节
- 原则：优先采用国家密码管理局、全国标准信息公共服务平台的现行标准信息；标准编号、年份和状态不凭记忆填写。
- 注意：标准能证明“体系/接口/安全要求存在”，不能直接证明某一具体 SoC/板卡已经完整实现全部能力。

## 1. 可信计算体系结构与密码支撑平台

### S-CN01 — GB/T 38638-2020《信息安全技术 可信计算 可信计算体系结构》

- 类型：国家标准，推荐性，现行
- 发布：2020-04-28
- 实施：2020-11-01
- 2025-12-08 复审结论：继续有效
- 主管/归口：国家标准委 / TC260
- 作用：提供可信计算体系结构层面的总体依据，用于说明可信计算不是“单颗密码芯片”，而是由可信根、可信度量、可信报告、可信软件/平台等机制共同组成的体系。
- 官方入口：
  - https://std.samr.gov.cn/gb/search/gbDetailed?id=A47A713B763F14ABE05397BE0A0ABB25

### S-CN02 — GB/T 29829-2022《信息安全技术 可信计算密码支撑平台功能与接口规范》

- 类型：国家标准，推荐性，现行
- 发布：2022-04-15
- 实施：2022-11-01
- 替代：GB/T 29829-2013
- 作用：给出可信计算密码支撑平台的功能和接口规范，可用于支撑 Trust Service / Trusted Crypto Service 的平台化设计，而不是把上层应用直接绑定某颗安全芯片。
- 官方入口：
  - https://std.samr.gov.cn/gb/search/gbDetailedCNF?id=DD3D95E5C12171EBE05397BE0A0AF33F

### S-CN03 — GM/T 0011-2023《可信计算 可信密码支撑平台功能与接口规范》

## 6. 对无人装备 Trust Plane 的映射

| Trust Plane 能力 | 可引用的国内标准依据 | 说明 |
|---|---|---|
| 可信计算总体架构 | GB/T 38638-2020 | 支撑“可信计算是体系，不是单器件” |
| 可信密码服务平台 | GB/T 29829-2022、GM/T 0011-2023 | 支撑 Trust Service / cryptographic support platform |
| TCM 接口 | GM/T 0012-2020 | 支撑可信密码模块集成 |
| TCM 符合性测试 | GM/T 0013-2021 | 支撑接口验证 |
| TCM 服务层 | GM/T 0058-2018 | 支撑 service module 抽象 |
| 平台证明 | GM/T 0079-2020 | 国内直接匿名证明规范 |
| TCM 本体安全 | GM/T 0082-2020 | 可信密码模块保护轮廓 |
| 通用密码模块安全 | GM/T 0028-2024 | 密码模块产品安全要求 |
| 安全芯片检测 | GM/T 0008-2012 | 独立安全芯片/SE 证据入口 |
| 密码应用实施 | GM/T 0132-2023 | 从器件能力走向系统实施 |
| 密码应用测评 | GM/T 0115-2021 | 从“有功能”走向“可测评” |
| 设备/软件/模型签名 | GB/T 32918.2-2016 | SM2 签名 |
| 完整性测量 | GB/T 32905-2016 | SM3 hash |
| 数据/模型加密 | GB/T 32907-2016 | SM4 对称加密 |

## 7. 工程判断边界

- GM/T/GB/T 标准能为产品定义提供**规范依据**，但不会自动证明某候选 SoC 已实现完整 Trust Plane；
- 支持 SM2/SM3/SM4 不等于支持可信启动、度量启动或远程证明；
- 支持 TCM/TPM 接口不等于已经完成整机 Attestation 服务；
- 支持 Secure Boot 不等于符合 GB/T 38638 或 GM/T 0011 的全部可信计算能力；
- 最终产品需同时建立：器件符合性、平台集成、系统策略、应用测评和工程验证五层证据。
