# 参考资料索引与原始文献归档

本仓库参考资料分为两层：

- **证据/摘要层**：`papers/`、`standards/`、`webpages/`、`benchmarks/` 等目录，保存调研摘要、出处、原始 URL、技术判断依据。
- **原文快照层**：`archive/primary/`，仅保存已明确许可再分发的官方文档或开源项目 README，并在 `archive/licenses/` 保存许可文本。

关键入口：

- [最终报告 R01–R62 引用索引](final-report-reference-index-v0.5.md)
- [原文归档与高价值资料分类](archive/README.md)
- [62 条文献的本地归档状态](archive/reference-inventory-2026-10-08.csv)
- [上游 Commit/Blob SHA/许可证与本地路径](archive/source-manifest-2026-10-08.csv)

**说明：** 开放访问不必然等于可以转载。GB/T、GM/T、SAE 和不明授权的厂商文档不直接归档受限全文。源项目 README 快照不等于正式论文原文。
