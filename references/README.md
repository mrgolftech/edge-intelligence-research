# 参考资料索引与原始文献归档

本仓库参考资料分为两层：

- **证据/摘要层**：`papers/`、`standards/`、`webpages/`、`benchmarks/` 等目录，保存调研摘要、出处、原始 URL、技术判断依据。
- **原文快照层**：`archive/primary/`，仅保存已明确许可再分发的官方文档或开源项目 README，并在 `archive/licenses/` 保存许可文本。
