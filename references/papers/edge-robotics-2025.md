# 文献摘要：Edge Computing and Its Application in Robotics (2025)

- 文献：Edge Computing and Its Application in Robotics: A Survey
- 作者：Nazish Tahir, Ramviyas Parasuraman
- 期刊：Journal of Sensor and Actuator Networks
- 2025, 14(4), 65
- DOI：https://doi.org/10.3390/jsan14040065
- 获取日期：2026-09-30
- 可信度：高（Open Access Survey）

## 已确认事实

综述强调 edge computing 对机器人系统的价值包括：
- reduced latency
- mobility support
- location awareness
- real-time processing near data source

文中指出：
- cloud-only 会受到 network delay / congestion / connectivity 的限制；
- perception、SLAM、navigation 等可产生大量数据和实时计算需求；
- edge 可用于 SLAM、multi-robot、task offloading 等场景；
- 实际系统还面临 network variability、fault tolerance、orchestration、scalability 等挑战。

## 对本项目支撑

不能将系统简单划分为“全部 onboard”或“全部 cloud”。

后续部署架构需要按 workload 的：
- latency
- safety
- bandwidth
- connectivity tolerance
- energy
来决定 on-device / near-edge / cloud。
