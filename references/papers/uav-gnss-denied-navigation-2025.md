# 文献摘要：GNSS-Denied UAV Navigation (2025)

- 文献：Gnss-denied unmanned aerial vehicle navigation: analyzing computational complexity, sensor fusion, and localization methodologies
- 类型：Open Access Review
- 期刊：Satellite Navigation
- 发布时间：2025-04-07
- 获取日期：2026-09-30
- 可信度：高
- URL：https://link.springer.com/article/10.1186/s43020-025-00162-z

## 已确认事实

该综述分析 132 篇近期 UAV localization 研究。

其主要分类：
- Absolute Localization
- Relative Localization

覆盖技术：
- INS
- vision
- LiDAR
- terrain-aided navigation
- SLAM
- Visual Odometry
- Visual-Inertial Odometry
- Kalman Filter
- AI-based methods
- multi-modal sensor fusion

文献特别强调：
- GNSS拒止环境是 UAV 自主导航核心问题；
- multi-modal sensor fusion 对准确性与可靠性重要；
- 研究中大量工作包含真实实验，而不只仿真；
- 计算复杂度和实际部署可行性需要考虑。

## 对本项目支撑

支持以下结论：
1. UAV端侧负载必须包含定位/融合，而不只是目标检测；
2. VIO/SLAM 是重要工作负载；
3. 算力推导必须考虑传感器组合和算法架构。

## 限制

该文聚焦 localization，不覆盖 UAV 任务管理、payload AI、通信、多机协同的全部需求。
